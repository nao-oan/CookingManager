# S-1 レシピ提案画面 デザインカンプ制作ブリーフ

## 用途

CookingManager は、冷蔵庫の在庫から「いま作れる料理」を提案する個人用のスマートフォン Web アプリ。

作るのは **S-1 レシピ提案画面**。ログイン直後に最初に開く画面で、
**今日何を作るかをその場で決めさせる**ことだけが目的。キッチンで片手で見る。

この画像はトーンを決めるためのビジュアル探索であり、実装仕様ではない。
採用する方向が決まってから、別途コードに起こす。

## 出力

担当スロット `<SLOT>`（A / B / C のいずれか）はプロンプトで指定される。

```
docs/design/mockups/s-1/<SLOT>/gen/<SLOT>1.png
docs/design/mockups/s-1/<SLOT>/gen/<SLOT>2.png
docs/design/mockups/s-1/<SLOT>/gen/<SLOT>3.png
```

- ツール: `image_gen`（gpt-image-2）。使えない場合は代替手段にフォールバックせず即報告する
- サイズ: 768 × 1664
- quality: high
- `background: transparent` と `input_fidelity` は指定しない

## それ以外

デザイン、配色、書体、レイアウト、画面内の文言、載せるレシピの件数と内容、
3案の振り分け方は**すべて任せる**。ここに書かれていないことは指示ではなく、各自の判断でよい。

他スロットのディレクトリは触らない。`git commit` / `git push` はしない。
